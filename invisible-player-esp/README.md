# Invisible Player ESP

Клиентский Fabric-мод для Minecraft Java Edition **1.21.4**. Подсвечивает игроков под эффектом невидимости контуром выбранного цвета, виден сквозь блоки.

## Установка

1. Java 21 и [Fabric Loader](https://fabricmc.net/use/installer/) для Minecraft 1.21.4.
2. [Fabric API](https://modrinth.com/mod/fabric-api) для 1.21.4 (проект собран против `0.119.4+1.21.4`).
3. Скопируйте `invisibleesp-1.0.0.jar` в папку `mods` (не `-sources.jar`).
4. Запустите игру с профилем Fabric 1.21.4.

## Сборка из исходников

```
./gradlew build        # Windows: gradlew.bat build
```

Готовый мод: `build/libs/invisibleesp-1.0.0.jar`. Нужны Java 21 и доступ в интернет
(Gradle скачает Loom, Minecraft, Yarn-маппинги и Fabric API с maven.fabricmc.net).

## Управление

Обе клавиши меняются в Настройки -> Управление -> Invisible Player ESP.

| Клавиша | Действие |
|---|---|
| RIGHT SHIFT | открыть / закрыть меню настроек |
| H | включить / выключить ESP |

## Меню настроек

- **ESP** — главный выключатель.
- **Player Name** — ник над невидимым игроком.
- **Through Walls** — вкл: контур виден всегда; выкл: только при прямой видимости.
- **Render Distance** — дальность подсветки, 8-128 блоков.
- **Brightness** — яркость контура, 10-100 %.
- **ESP Color** — цвет через три слайдера R/G/B с предпросмотром.

Настройки хранятся в `config/invisibleesp.json`.

## Как это работает

Мод не рисует свою геометрию, а включает штатный механизм «свечения» (Glowing) Minecraft для невидимых игроков:

- `MinecraftClientMixin` — `hasOutline` возвращает `true` для подсвечиваемых игроков;
- `EntityMixin` — цвет контура берётся из настроек (`getTeamColorValue`);
- `LivingEntityRendererMixin` — принудительно показывает ник (у невидимых игроков ваниль его скрывает).

Контур рисуется в отдельный буфер поверх мира, поэтому виден сквозь стены. Броня и предметы в руках
рисуются обычными слоями рендера и тоже попадают в контур, если клиент их получил.

Обнаружение: проверяется эффект `StatusEffects.INVISIBILITY` и флаг невидимости сущности. Ванильный сервер
не отправляет другим игрокам список чужих эффектов, зато выставляет флаг невидимости — по нему мод и находит цель.

## Ограничения

- Мод видит только тех игроков, чьи сущности сервер отправил клиенту. Если сервер скрывает сущность
  (плагины, anti-ESP, дальность прорисовки), обнаружить её нельзя, и мод не пытается это обойти.
- Толщина контура зашита в шейдер ванильного свечения, мод её не меняет.
- Ник отображается на дистанции до 64 блоков (ограничение ванильного рендера имён).
- Шейдерпаки (Iris/OptiFine) могут отключать ванильные контуры сущностей.
- На многих серверах подобные моды запрещены правилами — проверяйте правила перед использованием.
